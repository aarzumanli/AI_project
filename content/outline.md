## 1. Module Overview

This learning module introduces three fundamental areas of computer science: algorithms, data structures, and connectionist artificial intelligence.

The module is designed for beginners who have basic computer literacy but little or no prior knowledge of these topics. Concepts will be introduced through clear explanations, visual diagrams, worked examples, pseudocode, and practical exercises.

The three areas will be connected through examples showing how algorithms process information, how data structures organize it, and how neural networks use computations to generate predictions.

## 2. Learning Outcomes

By the end of this module, learners should be able to:

- Define an algorithm and describe its main characteristics.
- Read and trace simple pseudocode and flowcharts.
- Explain and perform linear search and binary search.
- Describe Bubble Sort and trace its basic operations.
- Explain the purpose of Big O notation and compare simple growth rates.
- Identify arrays, linked lists, stacks, queues, trees, and graphs.
- Select an appropriate data structure for a simple problem.
- Explain artificial neurons, weights, bias, and activation functions.
- Describe the basic architecture of a feedforward neural network.
- Trace a small numerical neuron example.
- Summarize prediction, loss calculation, and weight updating during training.
- Explain how algorithms and data structures support AI applications.

## 3. Prerequisites

Learners are expected to have:

- Basic computer literacy.
- Familiarity with simple arithmetic.
- A basic understanding of variables, introduced where necessary.
- Willingness to follow step-by-step examples and complete practice activities.

No previous knowledge of neural networks or advanced programming is required.

## 4. Module Structure

### Part A: Algorithm Fundamentals

**Goal:** Understand what algorithms are, how they solve problems, and how their efficiency can be compared.

#### A1. Introduction to Algorithms
- Definition and purpose of an algorithm.
- Inputs, processing steps, and outputs.
- Characteristics of a clear algorithm.
- Everyday examples of step-by-step problem solving.

**Learning activity:** Describe an everyday task as an ordered sequence of steps.

**Status:** Planned.

#### A2. Pseudocode and Flowcharts
- Purpose of pseudocode.
- Basic sequence, selection, and repetition.
- Common flowchart symbols.
- Converting a simple problem into pseudocode or a flowchart.

**Learning activity:** Write pseudocode for finding the largest of three numbers.

**Status:** Planned.

#### A3. Linear Search
- Searching through a collection of elements.
- Checking elements one at a time.
- Tracing successful and unsuccessful searches.
- Understanding the number of comparisons.

**Learning activity:** Find a target value in an unsorted list.

**Status:** Planned.

#### A4. Binary Search
- The importance of sorted input.
- Comparing the target with the middle element.
- Repeatedly reducing the search interval.
- Tracing successful and unsuccessful searches.
- Comparing binary search with linear search.

**Learning activity:** Trace binary search on a sorted array and explain why each half can be eliminated.

**Status:** Initial lesson draft prepared; technical review and verification required.

#### A5. Introduction to Sorting: Bubble Sort
- Why data sometimes needs to be sorted.
- Comparing adjacent elements.
- Swapping elements when they are in the wrong order.
- Tracing a simple sorting example.
- Understanding the limitations of simple sorting methods.

**Learning activity:** Sort a small list manually and record each pass.

**Status:** Planned.

#### A6. Introduction to Time Complexity
- Why algorithm efficiency matters.
- The basic idea of Big O notation.
- Constant, linear, and quadratic growth.
- Comparing simple algorithms as input size increases.
- Introductory comparison of linear search and binary search.

**Learning activity:** Compare the maximum number of checks required by different searching methods.

**Status:** Planned.

### Part B: Data Structures

**Goal:** Understand how data can be organized and accessed, and select suitable structures for simple scenarios.

#### B1. Introduction to Data Structures
- Definition and purpose of a data structure.
- Organizing and accessing information.
- Choosing structures according to the problem.
- Relationship between data structures and algorithms.

**Learning activity:** Choose ways to organize student records or a waiting list.

**Status:** Planned.

#### B2. Arrays
- Storing elements in an ordered collection.
- Indexing and accessing elements.
- Reading and updating values.
- Advantages and limitations of arrays.

**Learning activity:** Access and update specified elements in a sample array.

**Status:** Planned.

#### B3. Linked Lists
- Nodes and links.
- Head and next references.
- Basic traversal and insertion concepts.
- Differences between arrays and linked lists.

**Learning activity:** Draw a linked list and trace its connections.

**Status:** Planned.

#### B4. Stacks
- The Last In, First Out (LIFO) principle.
- Push, pop, and peek operations.
- Practical examples, such as undo operations.

**Learning activity:** Trace a sequence of push and pop operations.

**Status:** Planned.

#### B5. Queues
- The First In, First Out (FIFO) principle.
- Enqueue and dequeue operations.
- Practical examples, such as a waiting line.
- Comparison between stacks and queues.

**Learning activity:** Trace arrivals and departures in a queue.

**Status:** Planned.

#### B6. Trees
- Nodes, edges, roots, parents, and children.
- Basic tree structure.
- Simple hierarchical relationships.
- Examples such as folder structures.

**Learning activity:** Draw a tree representing a simple hierarchy.

**Status:** Planned.

#### B7. Graphs
- Vertices and edges.
- Representing relationships and connections.
- Directed and undirected graph concepts.
- Examples such as roads and social networks.

**Learning activity:** Represent a small network as a graph.

**Status:** Planned.

#### B8. Comparing Data Structures
- Comparing arrays and linked lists.
- Comparing stacks and queues.
- Understanding tree and graph use cases.
- Selecting structures based on simple requirements.

**Learning activity:** Match real-world scenarios to suitable data structures and justify each choice.

**Status:** Planned.

### Part C: Connectionist Artificial Intelligence

**Goal:** Explain the basic computational principles of artificial neurons and neural networks.

#### C1. Introduction to Connectionist AI
- What connectionist AI means.
- The idea of learning through interconnected computational units.
- Basic applications of neural networks.
- High-level comparison with rule-based approaches.

**Learning activity:** Identify possible uses of neural networks in everyday technology.

**Status:** Planned.

#### C2. Artificial Neurons
- Inputs and weights.
- Bias.
- Weighted sums.
- Activation functions.
- How a neuron produces an output.

**Learning activity:** Trace a small numerical example of an artificial neuron.

**Status:** Planned.

#### C3. Feedforward Neural Networks
- Input, hidden, and output layers.
- Connections between neurons.
- Forward propagation of information.
- How a network produces a prediction.

**Learning activity:** Trace information through a small network diagram.

**Status:** Planned.

#### C4. Introduction to Neural Network Training
- Predictions and target values.
- The purpose of a loss function.
- The general idea of adjusting weights.
- High-level introduction to gradient-based optimization and backpropagation.
- Difference between making a prediction and learning from errors.

**Learning activity:** Explain how an incorrect prediction can help guide a future adjustment.

**Status:** Planned.

#### C5. Applications and Limitations
- Examples of neural network applications.
- The importance of training data.
- Potential errors and limitations.
- Why evaluation and human oversight matter.

**Learning activity:** Discuss a neural network application and identify one possible limitation.

**Status:** Planned.

### Part D: Connecting the Three Areas

**Goal:** Show how algorithms, data structures, and connectionist AI contribute to larger computing systems.

#### D1. Algorithms and Data Structures in Applications
- How algorithms operate on organized data.
- Choosing data structures for efficient processing.
- Examples involving search, records, and networks.

**Learning activity:** Design a simple process for searching a collection of records.

**Status:** Planned.

#### D2. Data Processing and Neural Networks
- Organizing input data.
- Applying computations to inputs.
- Producing and evaluating predictions.
- Understanding the role of algorithms in AI systems.

**Learning activity:** Map the stages from input data to a neural network prediction.

**Status:** Planned.

## 7. Assessment Strategy

Learner understanding will be checked through:

- Short definition and concept questions.
- Step-by-step algorithm tracing.
- Searching and sorting exercises.
- Data-structure operation tracing.
- Data-structure selection scenarios.
- Small numerical neuron calculations.
- Questions explaining basic neural network training.
- Integrated questions connecting the three subject areas.

Answers should include explanations so learners can understand their mistakes and improve.

## 8. Scope Boundaries

The first teaching version will prioritize conceptual understanding and simple worked examples.

**Included:**
- Linear search, binary search, and Bubble Sort.
- Introductory Big O comparisons.
- Arrays, linked lists, stacks, queues, trees, and graphs.
- Artificial neurons and feedforward networks.
- Introductory prediction, loss, and weight updating.

**Outside the initial scope:**
- Advanced algorithm proofs.
- Balanced-tree implementations.
- Detailed graph algorithm implementations.
- Calculus-based neural network derivations.
- Large-scale model engineering.

Backpropagation and gradient-based optimization will be introduced conceptually rather than derived mathematically.
