# Module Outline - Algorithms, Data Structures & Connectionist AI

**Audience:** Beginner / first-year university learners with basic computer literacy.  
**Stage:** V1.0  
**Purpose:** Organize the three project strands into one coherent beginner learning sequence and show current development status.

## Intended learning outcomes

By the end of the planned module, learners should be able to:

- explain what an algorithm is and follow simple pseudocode step by step;
- distinguish linear search from binary search and recognize that ordinary binary search requires sorted input;
- identify common data structures including arrays, linked lists, stacks, queues, trees, and graphs;
- explain why the organization of data affects how it can be processed;
- explain the introductory idea of connectionist AI using artificial neurons, weights, biases, predictions, training, and loss;
- connect algorithms, data structures, and a trained model within a simple application;
- use predict-trace-check to reason about a computational process.

## Prerequisite knowledge

- Basic computer literacy.
- No advanced programming or AI knowledge is assumed in the current chapter.

## Coherence of the module

The sequence starts with shared vocabulary and a simple method for tracing computational steps. It then moves from algorithms to the data structures those algorithms operate on, and finally to connectionist AI as a learning-based approach. The orientation chapter already uses a library catalogue, campus routes, and image classification to show how the three strands can appear in related applications.
